# Tandem Tales Client (Python)

This Python library provides the abstract `tt.Client` and `tt.Factory` classes
that can be extended to create [Tandem Tales](https://sgware.github.io/tt)
agents. See
[this example Python agent](https://github.com/sgware/tt-random-agent-python)
for a demonstration of how to download and run a Tandem Tales server, define a
Python agent, connect it to the server, and play with it.

## Download and Install

You can download and install this library using
[pip](http://pypi.org/project/pip/):
```
pip install git+https://github.com/sgware/tt-client-python
```

## Build from Source

To download this library and build it from source:
```
git clone https://github.com/sgware/tt-client-python.git
cd tt-client-python
python -m build
pip install dist/tt-0.9.0-py3-none-any.whl
```

The documentation is generated by [MkDocs](http://www.mkdocs.org/). You can
regenerate it from the project root directory like this:
```
mkdocs build
```
